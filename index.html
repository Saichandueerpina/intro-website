    HOW WE COLLABORATE

    Our Git & GitHub Workflow

    We use version control to keep track of our code and work safely with other developers.

    01

    Clone

    Download a repository from GitHub to your computer.

    git clone REPOSITORY_URL
    02

    Edit

    Open the project in VS Code and make your changes.

    code .
    03

    Stage & Commit

    Prepare changes and save a snapshot in Git history.

    git add . git commit -m "Update website"
    04

    Push

    Upload your committed changes to GitHub.

    git push origin main
    05

    Pull

    Download and integrate the latest changes from GitHub.

    git pull origin main
    06

    Review & Merge

    Use a pull request to review and combine branch changes.

    git switch -c feature/about

    💡 Important Git tip

    Before starting work with a teammate, check your branch and working tree. Pull the latest changes when appropriate, and commit meaningful changes with clear messages. Avoid editing the same lines at the same time when possible.

    QUICK ANSWERS

    Frequently Asked Questions

    Some important concepts we use while learning web development.

    What is HTML?

    HTML stands for HyperText Markup Language. It defines the structure and content of a webpage using elements such as headings, paragraphs, links, and sections.

    What is CSS?

    CSS stands for Cascading Style Sheets. It controls how a webpage looks, including colors, layouts, fonts, spacing, animations, and responsive behavior.

    Why do we use JavaScript?

    JavaScript makes websites interactive. In this project, it generates team cards, changes themes, displays typed names, and copies the contact email.

    What is the difference between Git and GitHub?

    Git is a version control system that tracks changes to files. GitHub is an online platform for hosting Git repositories and collaborating with other developers.

    What is a pull request?

    A pull request proposes changes from one branch into another. Teammates can inspect the code, discuss improvements, and approve the changes before merging.

    How can we publish this website?

    You can publish a static HTML, CSS, and JavaScript website using GitHub Pages or another static hosting service. Make sure your file paths and repository settings are correct.
